# sysmlv2-demo





SysML v2 language transferred from its EMF implementation into the LionWeb format.



The f1re.sysmlv2.lionweb is an eclipse plug-in project, that allows for the transformation of an arbitrary ecore model into the LionWeb-compatible form, and for the export of an ecore metamodel into the LionWeb JSON format.



The models folder contains results of the model-to-model transformation and of the LionWeb language export for the ecore models of the SysML v2 project: https://github.com/Systems-Modeling/SysML-v2-Pilot-Implementation
