# sysmlv2-demo





In this project we transfer the open-source EMF implementation of the SysML v2 language into the LionWeb format.



The `f1re.sysmlv2.lionweb` is an eclipse plug-in project that allows for 
* the transformation of an arbitrary ecore model into the LionWeb-compatible form,
* the export of an ecore metamodel into the LionWeb JSON format.



The `model`s folder contains results of the model-to-model transformation and of the LionWeb language export applied to the ecore models of the SysML v2 project: [https://github.com/Systems-Modeling/SysML-v2-Pilot-Implementation]
